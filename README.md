## About

I'm a Computer Science undergraduate at **IIT Madras** interested in building software across layers of the stack — from digital logic and computer architecture to AI-powered applications.

I enjoy understanding how systems work from first principles and turning that understanding into practical projects. My work includes low-level computer construction, RAG-based document question answering, voice assistants, and automation.

## Featured Projects

| Project | What it does | Links |
|---|---|---|
| **DocuChat AI** | Chat with single or multiple PDFs using a RAG pipeline, semantic retrieval, Groq/LLaMA responses, and source citations with page numbers. | [Code](https://github.com/Bablu-Nayak/DocuChat-Ai) · [Live demo](https://docuchat-ai-bwehvfvs3ghjqqk7nmgte4.streamlit.app/) |

| **Jarvis** | A Python voice assistant using speech recognition, a Groq-hosted LLM, text-to-speech, browser actions, and voice commands. | [Code](https://github.com/Bablu-Nayak/Jarvis) |
